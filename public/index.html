A web page can't read your mailbox by itself. To pick up shipping emails automatically, run the small PackTrack helper on your computer. It reads the mailbox (read-only) and hands the packages it finds to this page.

  1. Download the project, then put your mail settings in .env (see .env.example; Gmail needs an app password).
  2. Run npm install and npm start.
  3. Enter the helper address (usually http://localhost:3000) in Settings.

Settings

Live tracking

PackTrack gets live status from a tracking aggregator that covers 1,000+ carriers (Posti, Matkahuolto, PostNord, DHL, UPS, FedEx, USPS, Cainiao, YunExpress…). All three have free tiers — add a key for at least one. Without a key you can still store packages and open the carrier's tracking page.
